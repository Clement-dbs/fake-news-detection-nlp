Détecteur de fake news

Ce projet propose une API et une interface web permettant de détecter automatiquement si un texte est une information réelle ou une fake news. Le modèle repose sur un algorithme NLP entraîné sur un dataset de titres réels et mensongers

L'API expose plusieurs endpoints exploitables :

  • GET /health : Vérifie que l'API est opérationnelle.
  • POST /predict : Permet de soumettre un texte et de recevoir la prédiction du modèle. Le corps de la requête doit contenir un JSON avec le champ text.
La réponse inclut le label prédit ("REAL" ou "FAKE"), la confiance du modèle, et les scores détaillés pour chaque classe.

PS: Le modèle à été entrainé sur des données issus de la langue anglaise et ne fonctionne donc que dans cette langue
